# 🦷 DentalCare Clinic Management System

![Preview](Dental%20care.png)

## 📌 Overview
DentalCare is a full-featured clinic management system designed to support daily operations of a dental clinic.  
The system provides an intuitive interface and robust backend to manage patients, appointments, treatments, and financial reports.

---

## 🚀 Features

### 👤 Patient Management
- Add, update, and manage patient records  
- Store personal and medical information  
- Easy navigation between patient profiles  

### 📅 Appointment Scheduling
- Book and manage appointments  
- View daily/weekly schedules  
- Prevent scheduling conflicts  

### 🦷 Treatment Plans
- Create and manage treatment plans  
- Track patient progress  
- Organize treatments per patient  

### 💰 Financial Reports
- Generate detailed reports using **JasperReports**  
- Track clinic income and expenses  
- Export reports for analysis  

---

## 🛠️ Technologies Used
- **Java (Swing)** – User Interface  
- **SQL** – Database queries  
- **Microsoft Access** – Database management  
- **JasperReports** – Reporting system  

---

## 🧠 System Design
- Layered architecture (Boundary, Controller, Entity)  
- Separation of concerns for maintainability  
- Scalable structure for future extensions  

---

## 🎯 Key Highlights
- Real-world simulation of a dental clinic system  
- Integration between UI, database, and reporting tools  
- Clean and structured code organization  
- Focus on usability and user experience
